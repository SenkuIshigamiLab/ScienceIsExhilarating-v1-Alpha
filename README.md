# ScienceIsExhilarating-v1-Alpha
Я молодой и начинающий программист, который изучает библиотеку FastAPI для создания сервера своего собственного веб-проекта. Этот проект нацелен на создание платформы для размещения исследований и простых ведений блога молодых или опытных ученых, которые увлечены наукой и ищут людей с таким же увлечением. Проект подходит также и для людей, которые интересуются наукой, но еще не являются активными участниками этого сообщества, желающие познакомиться с этим прекрасным миром исследований и раскрытий секретов и законов природы. Это начальная и сырая версия, которая будет еще долго дорабатываться, и я буду благодарен, если получу советы об улучшении моего нынешнего кода
